# ตัวอย่าง Paradigm: การจัดทำเอกสารองค์ความรู้

เอกสาร Paradigm ที่ดีควรอ่านแล้วนำไปใช้ต่อได้ทันที แนะนำให้มีโครงสร้าง 5 ส่วนดังนี้

## 1. ที่มาและบริบท (Background)

งานนี้คืองานอะไร เกิดขึ้นที่โครงการ/แผนกไหน ช่วงเวลาใด และใครเกี่ยวข้องบ้าง

## 2. ปัญหาหรือโจทย์ (Problem)

ปัญหาที่พบคืออะไร ส่งผลกระทบอย่างไร (เวลา ค่าใช้จ่าย คุณภาพ ความปลอดภัย)

## 3. แนวทางแก้ไข (Solution / Approach)

ทำอะไรไปบ้าง เป็นขั้นตอน ระบุเครื่องมือ เอกสารอ้างอิง หรือผู้เชี่ยวชาญที่เกี่ยวข้อง
แนบรูปภาพหรือแบบแปลนประกอบถ้ามี

## 4. ผลลัพธ์ (Result)

ผลที่ได้เทียบกับก่อนแก้ไข ถ้าวัดเป็นตัวเลขได้ให้ระบุตัวเลข

## 5. บทเรียนและข้อแนะนำ (Lesson Learned)

ถ้าต้องทำอีกครั้งจะทำอะไรต่างไป และข้อควรระวังสำหรับทีมอื่นที่จะนำไปใช้

---

**เคล็ดลับการตั้ง Tag:** ใส่ Tag ทั้งชื่อโครงการ ประเภทงาน และคำที่คนน่าจะใช้ค้นหา เช่น `งานฐานราก`, `โครงการ A`, `ลดต้นทุน` เพื่อให้เพื่อนร่วมทีมค้นเจอง่ายที่สุด
