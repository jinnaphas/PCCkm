# คู่มือการใช้งาน Paradigm Library

ยินดีต้อนรับสู่ **Paradigm Library** — คลังเก็บองค์ความรู้ (Paradigm) ของทีม ที่ใช้งานได้ผ่าน Browser ทั้งหมด

## การค้นหาเอกสาร

- ใช้ช่อง **ค้นหา** ด้านบนของหน้าจอ พิมพ์คำที่ต้องการ ระบบจะค้นจาก **ชื่อเอกสาร, Tag และคำอธิบาย** ทันทีที่พิมพ์
- หรือกดเลือก **หมวดหมู่** จากหน้าแรก เพื่อไล่ดูเอกสารในหมวดนั้น แล้วกรองด้วย Tag ได้อีกชั้น

## การเปิดดูเอกสาร

กดที่ชื่อเอกสารเพื่อเปิดหน้ารายละเอียด ซึ่งจะแสดง:

- ตัวอย่างเอกสาร (Preview) สำหรับไฟล์ PDF, รูปภาพ, วิดีโอ และ Markdown
- ปุ่ม **ดาวน์โหลด** สำหรับไฟล์ทุกประเภท
- **ประวัติเวอร์ชัน** ทั้งหมดของเอกสาร ย้อนดูไฟล์เวอร์ชันเก่าได้

## การอัพโหลดเอกสารใหม่

1. กดปุ่ม **เข้าสู่ระบบ** มุมขวาบน กรอกชื่อของคุณ และ GitHub Token (ขอวิธีสร้าง Token จากผู้ดูแลระบบ หรือดูใน README ของ repo)
2. กดปุ่ม **+ เพิ่มเอกสาร**
3. เลือกไฟล์ กรอกชื่อ คำอธิบาย เลือกหมวดหมู่ และใส่ Tag
4. กดบันทึก — เอกสารจะถูกเก็บเข้าคลังทันที

> สำหรับวิดีโอขนาดใหญ่ แนะนำให้อัพโหลดเป็น **ลิงก์ภายนอก** (เช่น ลิงก์ YouTube หรือ Google Drive) แทนการอัพโหลดไฟล์ตรง

## การอัพเดตเอกสารเดิม

เปิดหน้าเอกสารที่ต้องการ แล้วกดปุ่ม **อัพเดตเวอร์ชัน** เลือกไฟล์ใหม่พร้อมบันทึกว่าแก้อะไรไป ระบบจะเพิ่มเลขเวอร์ชันให้อัตโนมัติ และเก็บไฟล์เวอร์ชันเก่าไว้ให้ย้อนดูได้เสมอ
